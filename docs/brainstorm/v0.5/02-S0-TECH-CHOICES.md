## 1. Typed IPC between Rust and TypeScript

**Plain answer:** the GUI calls Rust functions ("commands") and listens to Rust "events". If the TypeScript side is written by hand, it slowly drifts from Rust and bugs appear. So we **generate** it (Constitution Art. 1).

| Option | What it generates | Status (2026-10-10) | Pros | Cons |
|---|---|---|---|---|
| **tauri-specta** ⭐⭐ | Types **plus** typed `commands.*` wrappers **plus** typed events | `2.0.0-rc.25` (May 2026); still a release candidate after ~2 years | One `collect_commands!` / `collect_events!` → everything typed end to end | RC: exact pin required; occasional breaking changes |
| **ts-rs** ⭐ | Types only | `12.0.1`, stable, very popular (~7.5 M recent downloads) | Stable, simple | Command and event wrappers must be generated by our own `atabey-gen` (≈ 200 lines) or written by hand (forbidden) |
| TauRPC | Trait-based typed IPC | 0.8 | Elegant API | Smaller community; another abstraction |
| Hand-written types | — | — | Zero dependencies | Violates Art. 1 |

**What others do:** Spacedrive and Cap (large Tauri apps) use specta / tauri-specta; many smaller apps hand-write `invoke()` calls; Electron apps typically share TS types because both sides are TS.
**Recommendation:** tauri-specta, pinned, with ts-rs as the documented fallback (already in the spec's risk table).

## 2. Where Markdown is parsed

| Option | Pros | Cons |
|---|---|---|
| **Rust (comrak) → typed AST → React** ⭐⭐ | **One parser** for rendering, indexing (SQLite), schema validation, question detection, the CLI and (later) agents; typed blocks validated by the same Rust types | AST travels over IPC (fine: documents are small); fewer ready-made plugins than remark |
| TS (unified/remark → React) ⭐ | Huge plugin ecosystem; `react-markdown` is plug-and-play | The core would need a **second** parser for indexing/validation → two parsers that can disagree |

**What others do:** VS Code's Markdown preview uses markdown-it in TS; Zed renders Markdown in Rust (pulldown-cmark); Obsidian uses its own TS parser; GitHub renders with cmark-gfm (C) on the server.
**Recommendation:** Rust. Atabey's documents are *data* (decisions, questions, findings) first and pages second.

## 3. Frontend stack

| Area | Proposed ⭐⭐ | Alternatives | Why |
|---|---|---|---|
| Framework | React 19.3 + TS 7 (strict) | — | D-015 |
| Build | Vite 8 | — | Tauri default |
| Styling | **Tailwind 4 mapped to semantic tokens** + Radix primitives | CSS Modules (⚪: explicit, no utility classes); a component kit like MUI (⚠️: fights the theme system) | Agents write Tailwind fluently; tokens keep themes swappable (D-091) |
| Routing | TanStack Router | React Router (⚪) | Fully typed routes |
| Server state | TanStack Query (IPC calls as queries) | Hand-rolled hooks (⚪) | Caching, invalidation on events |
| UI state | Zustand | Redux Toolkit (⚪: heavier), Jotai (⚪) | Tiny, simple |
| Lint/format | Biome | ESLint + Prettier (⚪: slower, more config) | One tool |
| Package manager | pnpm | npm (⚪), Bun (⚪: fast; occasional Tauri/tooling gaps) | Workspaces, disk-efficient |

**What others do:** Zed doesn't use a webview at all (GPUI); VS Code uses its own DOM framework; Cursor and Windsurf (VS Code forks) inherit it; modern Tauri apps (e.g., Spacedrive) commonly use React + Tailwind + Radix/shadcn + TanStack.

## 4. Extension UI isolation

**Plain answer:** extension panels must not be able to call Atabey's internal API directly. Otherwise a buggy or malicious extension could read your files or keys.

**What I found (2026-10-10):** a 2024 Tauri advisory (CVE-2024-35222) showed that iframes could reach Tauri's IPC. After the fix (Tauri ≥ 2.0.0-beta.20), **iframes can no longer invoke commands**, except on Windows when the iframe has the **same origin** as the app, and an "invoke key" blocks forged messages from sub-frames. The advisory recommends dedicated windows/webviews for untrusted content.

| Option | Isolation | Effort | Fits D-100? |
|---|---|---|---|
| **Sandboxed iframe, opaque origin (`sandbox="allow-scripts"`, no `allow-same-origin`), served from `atabey-ext://`, strict CSP, `postMessage` bridge; verified by a spike test on macOS + Windows (T-04)** ⭐⭐ | Good: opaque origin ≠ app origin, so even the Windows exception doesn't apply | Low | ✅ as decided |
| Dedicated webview per extension panel (Tauri multi-webview) ⭐ | Strongest | Medium–high (layout sync, focus) | Amendment to D-100 |
| Plain iframe, same origin | ❌ Can reach IPC on Windows | Low | ⚠️ |

**What others do:** VS Code webviews = iframes on a separate origin + `postMessage` (the model we copy); Obsidian runs plugins with **full access** (no isolation); Figma plugins = sandboxed iframe + main-thread sandbox; Zed has no extension UI.
**Recommendation:** iframes now (S0 only runs first-party extensions), **prove isolation with an automated test**, and revisit dedicated webviews before third-party extensions are allowed (S9).

## 6. GitHub repo visibility & CI cost

**Official prices (GitHub docs, checked 2026-10-10):** Linux $0.006/min · Windows $0.010/min · **macOS $0.062/min**. **Public repos: free** on standard runners. Private repos: 2,000 included minutes/month (Free plan) or 3,000 (Pro). The official page doesn't say how Windows/macOS minutes count against that allowance; secondary sources say they count at **2×** and **10×**.

**Estimate for S0** (one full CI run ≈ 2 min Linux lint + ~12 min Windows + ~12 min macOS, with caches):

| Setup | Runs/month | Est. cost/month |
|---|---|---|
| **Public repo**, full matrix on every push ⭐⭐ | unlimited | **$0** |
| Private, full matrix on every push (~60 pushes) | ~60 | ≈ $45–55 beyond the allowance (macOS dominates) ⚠️ |
| Private, **Linux + Windows on every push; macOS only on merges to `main` + weekly** ⭐ | ~60 / ~15 | ≈ $0–12 (likely within the allowance if the 10× rule doesn't apply) |
| No CI (local only) | — | $0, but violates D-016 ⚠️ |

**Public ≠ release.** A public repo makes the code visible, but D-108 is about *offering* Atabey to others with Claude sign-in. The code never contains credentials (Art. 5–6). Two things to know before going public: (1) "Atabey" hasn't been trademark-checked yet; (2) your brainstorm history becomes public too (it's under `docs/brainstorm/`).

**What others do:** most open-source Tauri apps are public and use free CI; private projects usually run macOS CI only on release branches or use self-hosted Mac runners (free of GitHub charges as of 2026-09; you'd use your own Mac, which must stay on).

🛡️ **Safety either way:** if your GitHub account has a payment method, set the Actions **budget to $0** so usage stops instead of billing you (step in [04-ACTION](04-ACTION-GITHUB-REPO.md)).

## 7. How we work during implementation

| Option | How | Pros | Cons |
|---|---|---|---|
| **Branch + PR per task, CI must pass, you review and merge** ⭐⭐ | `s0/t-09-project-model` → PR → green → you merge | Every task reviewable; CI gates; clean history; matches Spec-Lite's loop | A bit slower |
| Commit directly to `main` ⚪ | Agent commits after each task | Fast | No review gate; CI failures land on `main` |
| Stacked PRs ⚪ | Several dependent PRs at once | Parallel work | Overkill solo |

**What others do:** Claude Code and Codex both create branches/PRs on request; Spec Kit uses one branch per feature; GitHub's Copilot coding agent always opens a PR.

## 8. Smaller choices already made in the spec

These follow directly from earlier decisions or licenses, so they're not questions. Say so in v0.5-Q13 if you disagree.

| Choice | Reason |
|---|---|
| **Tauri 2.12**, not 3.0 alpha | Stability; Tauri isolated in one crate for a later migration |
| **gix** instead of git2 | git2 wraps libgit2 (GPL-2.0 with linking exception), which isn't on the allowed license list |
| **serde-saphyr** for YAML | `serde_yaml` is officially deprecated |
| **WebdriverIO + `@wdio/tauri-service`** for E2E | The plain `tauri-driver` route doesn't support macOS; the WebdriverIO service embeds a WebDriver server (test builds only) |
| **OpenRouter only** in the S0 gateway | OpenCode Go only through the OpenCode runtime (Product Spec amendment A-1) |
| SQLite index **rebuilt** on schema change, no migrations | It's a derived index (D-020) |
| `Decimal` for money, local-midnight day boundary | Correct budget math |
| Raw HTML in Markdown **escaped** | Security; nothing in the docs needs it |
